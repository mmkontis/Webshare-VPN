# Webshare VPN

Tools for using your own Webshare proxies. Each platform lives in its own folder so additional apps can be added later.

## Chrome extension

The [Chrome extension](Chrome%20extension/) includes site routing, a green active indicator, download speed, HTTP latency, and a Test all proxies button.

[Preview and setup guide](https://humanlike.co/apps/webshare-vpn) · [Download the Chrome ZIP](https://github.com/mmkontis/Webshare-VPN/releases/latest)

If you clone this repository, choose the `Chrome extension` folder when loading it in Chrome. The release ZIP contains only the Chrome extension and extracts to `Webshare-VPN`, which is ready to load.

See the [Chrome installation and development instructions](Chrome%20extension/README.md).

This is an independent project, unaffiliated with Webshare. It routes Chrome traffic through HTTP proxies.
